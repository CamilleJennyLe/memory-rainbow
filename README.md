# Memory game

Play it here:
https://memory-rainbow.vercel.app/

## Why this project was born

1. My brain is suffering from the lack of sleep due to some parenting. I have some memory issues sometimes...thought this game would help.
2. I also needed a project I could show publicly so why not.

# Features

- Two card decks available: Rainbow Colors and Cats
- Memory game with 12 cards per game
- Enjoy a fun fact displayed every time you win
